## 🎯 Project goal

Build my first complete native iOS project with a clear scope instead of trying to create a huge streaming platform from the beginning.

The first version should complete one strong journey:

**collection → search → film details → favourites → trailer**

## 🗺️ Planned flow

<p align="center">
  <a href="./assets/concept-map.svg"><img src="./assets/concept-map.svg" alt="CineFlow user journey" width="780" /></a>
</p>

## 01 · 🧱 Foundation

- Tab Bar: Home, Catalogue, Favourites, Profile;
- poster collections;
- film detail screen;
- API-driven catalogue;
- deliberate loading / empty / error states.

## 02 · ❤️ Personal space

- search;
- filters;
- favourites;
- viewing history;
- on-device trailer position restoration.

## 03 · 🎞️ Media

- legal trailers;
- AVPlayer playback;
- playback-state handling;
- predictable return to the film screen.

## 04 · ⚙️ Architecture

- MVVM;
- separate service layer;
- URLSession;
- image caching;
- obsolete-request cancellation;
- predictable error handling.

## 05 · 🧪 Quality

- unit tests for core logic;
- iPhone Simulator verification;
- VoiceOver checks;
- polished empty states;
- original screenshots after implementation.

## ✅ Definition of ready

The roadmap status will only be removed when there is:

- a real Xcode project;
- a working build;
- iPhone Simulator verification;
- an implemented core user journey;
- original screenshots;
- reproducible tests.

Until then, the showcase deliberately remains an honest **project roadmap** instead of pretending a finished application exists.
